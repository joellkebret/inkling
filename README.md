Skribbl.io clone but with limited ink

## Goals
- Build a drawing canvas with a visible ink meter that runs down as you draw.
- Learn WebSockets by streaming strokes and guesses between players in real time.
- Run a full game in a private room with timed rounds, rotating drawers, and scoring.
- Save drawing strokes and timestamps in PostgreSQL so players can replay a round.
- Add bots so demos can be run without friends
